# Ecosystem Implementation Plan Order

Approved OneGodian ecosystem architecture is implemented in this order:

1. `2026-09-27-ecosystem-api-foundation.md`
2. `2026-09-27-ecosystem-valuation-mcp.md`
3. WordPress connector plan in `ohi-stack/onegodian-platform-plugin/docs/superpowers/plans/2026-09-27-gregory-onegodian-ecosystem-plugin.md`

The WordPress connector may begin against mocked API contracts after the foundation route schemas are locked, but production integration/ZIP acceptance requires the corresponding API foundation and valuation endpoints to be implemented and passing.

No plan stage should be described as production merely because its documentation has been approved. Production status requires the tests, persistence, security, OpenAPI, CI and packaging/deployment gates defined in each plan.
